DCC‑101v1 闭环步进电机串口通信协议说明书
1. 硬件连接与通信参数
本电机采用标准串口（UART）进行通信。下位机返回的数据均为 ASCII 字符串格式，且
均以回车换行符 \r\n 结尾。
・ 固定波特率：115200 bps (仅支持此速率)
・ 数据位：8 bit
・ 停止位：1 bit
・ 校验位：无 (None)
2. 系统开机与全局返回值说明
2.1 系统开机提示 (Boot Message)
电机上电或软件重启后，会从内部 Flash 读取保存的参数，并通过串口主动上报当前状
态：
・ 正常启动：
Boot OK: Mode=[模式], Cur=[电流], Org=[原点], Dir=[用户方向], HwDir=[硬件方向]\r\n
・ 异常启动 (Flash 数据损坏或未初始化，将加载默认值)：
Boot WARN(Err:[错误码]): Mode=[模式], Cur=[电流], Org=[原点], Dir=[用户方向], HwDir=[硬
件方向]\r\n
2.2 全局错误返回值
当上位机发送的指令格式不符合规范时，电机会拒绝执行并返回以下错误提示之一：
・ ERR: Header not found\r\n：未检测到合法的 AA 55 帧头（此错误不一定代表指令接收
失败）。
・ ERR: Frame incomplete\r\n：数据帧长度不足（被截断）。
・ ERR: Data length mismatch\r\n：声明的数据长度与实际接收长度不符。
・ ERR: Checksum failed (CMD:0x[指令码])\r\n：校验和计算错误，该帧被丢弃。
2
・ ERR: Unknown CMD 0x[指令码]\r\n：发送了系统不支持的未知指令码。
・ ERR: CMD 0x[指令码] length error\r\n：该指令的数据区长度 (LEN) 参数错误。

4. 校验和 (Checksum) 计算方法
校验和用于验证数据在传输过程中是否发生错误。
计算公式：Checksum = (设备 ID + 指令码 + 数据长度 + 数据区各字节之和) 的低 8 位
代码示例 (Python)：
# 假 设 payload = [ ID , CMD, LEN, DATA_1, DATA_2, . . . ]
checksum = sum( payload ) & 0xFF
5. 角度与脉冲换算规则

6. 指令集详解与返回值
0x11：相对旋转 (Relative Rotation)
控制电机以当前位置为起点，相对旋转指定的脉冲数。
・ 数据长度 (LEN)：0x05
・ 数据区(DATA)：[方向, 0x00, 0x00, 脉冲低字节, 脉冲高字节] (方向：0x00= 反转，0x01=
正转)
・ 成功返回值：CMD 0x11 OK, offset:[实际执行的脉冲偏移量]\r\n
0x12：设置当前为原点 (Set Origin)
将电机当前所处的位置清零，设为绝对坐标系的原点 (0 度)，并消除多圈累加偏移，自动
保存至 Flash。
・ 数据长度 (LEN)：0x00
・ 数据区 (DATA)：无
・ 成功返回值：CMD 0x12 OK, origin:[单圈物理原点值] saved, multi‑turn reset\r\n
0x13：绝对旋转 (Absolute Rotation)
控制电机旋转到相对于原点的绝对坐标位置。
・ 数据长度 (LEN)：0x03
・ 数据区 (DATA)：[方向, 脉冲低字节, 脉冲高字节] (方向：0x00= 负向逼近，0x01= 正向
逼近)
・ 成功返回值：CMD 0x13 OK, dir:[方向], tgt:[底层真实目标脉冲], diff:[计算出的差值]\r\n
4
0x14：设置运行电流 (Set Current)
设置电机运行时的最大电流限制，并自动保存至 Flash。
・ 数据长度 (LEN)：0x01
・ 数据区 (DATA)：[电流值] (范围：1 ~ 255，分别对应驱动板的 0A~ 最大电流档位，推荐
默认值 127，即一半电流工作)
・ 成功返回值：CMD 0x14 OK, current:[设置的电流值] saved\r\n
0x15：设置工作模式 (Set Mode)
切换电机的内部工作模式，并自动保存至 Flash。（此功能暂时没有实际作用）
・ 数据长度 (LEN)：0x01
・ 数据区 (DATA)：[模式值]
・ 成功返回值：CMD 0x15 OK, mode:[模式值] saved\r\n
0x16：用户逻辑方向设置 (Set User Direction)
反转用户的逻辑坐标系方向，并自动保存至 Flash。
・ 数据长度 (LEN)：0x01
・ 数据区 (DATA)：[方向控制] (0x00= 默认方向，0x01= 逻辑反转)
・ 成功返回值：CMD 0x16 OK, dir:[方向值] saved\r\n
・ 参数错误返回值：CMD 0x16 ERR, invalid dir\r\n
0x17：软件重启系统 (Software Reboot)
触发电机下位机软件复位重启。
・ 数据长度 (LEN)：0x00
・ 数据区 (DATA)：无
・ 成功返回值：CMD 0x17 OK, system rebooting...\r\n (注：发送此消息后约 1000ms 电
机将重启，随后会收到 Boot 启动信息)
